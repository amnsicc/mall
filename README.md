# 微商城

《Web 前端框架技术》课程项目，已完成第 6 周商品筛选练习。

## 功能

- 课程名片与 Vue Router 路由
- 可复用商品卡片与 Props 传值
- 商品列表、库存状态和购物车计数
- 商品收藏与取消收藏
- 关键词、分类、价格组合筛选与价格排序
- 回车搜索、商品单选高亮与本地草稿恢复
- 一键重置筛选，刷新后保留选中状态
- 假期云逛街商品统计页（`/holiday`）

## 运行

```powershell
pnpm install
pnpm dev
```

商品图片来源见 [IMAGE_SOURCES.md](./IMAGE_SOURCES.md)。
