# 微商城

《Web 前端框架技术》课程项目，已完成第 8 周路由与导航练习。

## 功能

- 课程名片与 Vue Router 路由
- 可复用商品卡片与 Props 传值
- 商品列表、库存状态和购物车计数
- 商品收藏与取消收藏
- 关键词、分类、价格组合筛选与价格排序
- 回车搜索、商品单选高亮与本地草稿恢复
- 一键重置筛选，刷新后保留选中状态
- SearchBar 的 defineModel 双向同步与 defineEmits 载荷校验
- 卡片插槽、网格/列表动态视图、KeepAlive 与滚动恢复
- v-focus 搜索框自动聚焦
- Hash 路由、商品动态详情、props 版详情、404 兜底
- 共享购物车、数量调整、库存上限与金额汇总
- 后台嵌套布局、模拟登录、导航守卫、登录后返回原地址
- 未保存管理备注的离开确认（取消时 return false 阻止导航）
- 假期云逛街商品统计页（`/holiday`）

## 运行

```powershell
pnpm install
pnpm dev
```

默认打开商品列表 `/#/products`，购物车 `/#/cart`，后台 `/#/admin`。
模拟登录可直接使用预填的 `student`，点击「模拟登录」。本周仅使用本地模拟数据和登录状态，不连接真实后端。
旧 `/list` 地址仍可访问，会转换到新的 Hash 路由。购物车在当前应用会话内共享，刷新后重置；草稿与选中状态保存在 localStorage。

## 验证

```powershell
pnpm test
pnpm build
```

自动测试覆盖筛选组合、排序不修改原数组、重置默认值、购物车数量与库存、模拟 API 成功与失败。
浏览器回归覆盖搜索/重置、视图缓存与滚动恢复、草稿高亮、事件转发、详情参数切换与刷新、props 详情、404、登录往返、嵌套路由与取消导航。
已检查 1440px、390px、320px 视口，控制台无错误或警告。

商品图片来源见 [IMAGE_SOURCES.md](./IMAGE_SOURCES.md)。

使用 Codex 辅助拆分组件、实现状态与事件、插槽和自定义指令、路由及模拟数据层、购物车、登录与导航守卫，以及编写验证脚本。
实现以教师课件和配套源码的验收项为依据，并保留第 6 周筛选、草稿与选中功能。
验证方式：`pnpm build`；使用 Playwright 实际操作搜索、重置、视图切换、滚动恢复和加购转发，检查浏览器错误与警告。
